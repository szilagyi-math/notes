# Security / Biztonság

Use [private vulnerability reporting](https://github.com/szilagyi-math/notes/security/advisories/new)
for security or privacy issues. Do not publish credentials, student identifiers,
names, exploit payloads containing personal data, or private spreadsheet data
in a public issue. Report only the minimum affected path, revision and behavior.
The maintained version is `main`; old course branches are archival.

Biztonsági vagy adatvédelmi hibát a fenti privát felületen jelents. Nyilvános
issue-ba ne kerüljön kulcs, név, hallgatói azonosító vagy privát táblázatadat.
Az érintett útvonal, revízió és viselkedés elegendő. Támogatott ág: `main`;
a régi kurzuságak archívumok.

Maintainers: revoke/rotate leaked credentials before coordinating history
cleanup. Treat forks and cached copies as leaked. Never rewrite history or
remove material destructively without explicit approval. See CONTRIBUTING.md
and docs/repo-hardening.md for known legacy privacy limitations.
